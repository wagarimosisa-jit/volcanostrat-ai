### Problem: "remote origin already exists" but wrong URL

**Solution:**
```cmd

```

---

### Problem: "non-fast-forward" or "Updates were rejected"

**Solution:**
```cmd
git pull origin main
:: Resolve any conflicts if they appear
git add .
git commit -m "Merged remote changes"
git push origin main
```

---

### Problem: "Repository not found" or "Authentication failed"

**Solution 1: Check URL**
```cmd
git remote -v
```
If wrong, fix it:
```cmd
git remote set-url origin https://github.com/wagarimosisa-jit/volcanostrat-ai.git
```

**Solution 2: Use GitHub Personal Access Token**
1. Go to GitHub > Settings > Developer Settings > Personal Access Tokens
2. Generate new token (classic)
3. Copy the token
4. When Git asks for password, paste the token instead

---

### Problem: "File too large"

**Solution:**
```cmd
:: Add to .gitignore
echo "large_file.zip" >> .gitignore

:: Remove from Git
git rm --cached large_file.zip
git commit -m "Remove large file"
git push origin main
```
